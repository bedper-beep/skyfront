
# SKYFRONT

An original battle royale shooter prototype built for the browser.

## Features

- Vibrant battlefield environment
- Solo survival gameplay prototype
- Shooting and enemy encounters
- Health, ammo, and combat HUD
- Desktop and mobile-friendly design

## Current Status

Early prototype in development.

## Planned Features

- Full 3D environment
- First-person and third-person cameras
- Multiple weapons and reload mechanics
- Loot and supply crates
- AI opponents
- Shrinking safe zone
- Mobile touch controls
- Online multiplayer in a future version

## Run Locally

Install Node.js, then run:

```bash
npm install
npm run dev
```

Open the local URL provided by Vite.

## Built With

- HTML
- JavaScript
- Vite
